# Contributing

Fork this repository, create a branch, and make your changes. Run the local server described in README.md and run `node scripts/check-world.mjs`. Include screenshots and a short explanation of changes to campus geometry, elevations or appearance. Open a pull request against main. The repository owner reviews and merges accepted changes. Pull requests run checks but do not deploy; accepted changes deploy after merging to main. Use Issues to report errors or suggest improvements. Do not add imagery or other assets without suitable rights and attribution.
